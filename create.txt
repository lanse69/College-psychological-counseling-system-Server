服务端工程 (PsyServer)

服务端负责数据持久化、业务逻辑校验和多用户并发处理。

1. 服务端目录结构

PsyServer/
├── CMakeLists.txt                  # 项目构建文件
├── config/
│   └── serverConfig.json          # 配置文件
├── src/
│   ├── main.cpp                    # 程序入口：加载配置 -> 连接数据库 -> 启动监听
│   ├── core/                       # 核心组件
│   │   ├── ServerApp.h/cpp         # 单例应用类，维护全局状态（如在线用户列表 `Map<UserId, Socket*>`）
│   │   └── ProtocolDefs.h          # 协议定义（虽不共享，但需在此定义 CMD_LOGIN, CMD_BOOK 等常量）
│   ├── network/                    # 网络层
│   │   ├── TcpListener.h/cpp       # 继承 QTcpServer，监听端口，接受新连接
│   │   └── ClientSocket.h/cpp      # 包装与客户端的 Socket 连接，负责收发原始 JSON 数据
│   ├── logic/                      # 业务逻辑层（处理具体请求）
│   │   ├── RequestRouter.h/cpp     # 路由分发器：根据 JSON 的 `cmd` 字段，将请求分发给对应的 Handler
│   │   ├── AuthHandler.h/cpp       # 处理登录、注销、识别用户身份（Student/Doctor/Admin）
│   │   ├── BookingHandler.h/cpp    # 核心逻辑：处理预约、冲突检测、状态流转（申请/同意/拒绝/完成）
│   │   ├── DoctorHandler.h/cpp     # 处理医生排班修改、个人信息修改
│   │   ├── SurveyHandler.h/cpp     # 处理问卷的上传、下发、答案提交
│   │   └── AdminHandler.h/cpp      # 处理管理员的数据导出请求（SQL 聚合查询）
│   └── dao/                        # 数据访问层 (Data Access Object)，直接操作 MySQL
│       ├── DBManager.h/cpp         # 创建数据库、表，数据库连接池管理
│       ├── UserDao.h/cpp           # 表操作：users (增删改查)
│       ├── ScheduleDao.h/cpp       # 表操作：doctorSchedules (排班表)
│       ├── AppointmentDao.h/cpp    # 表操作：appointments (预约记录)
│       ├── QuestionnaireDao.h/cpp  # 表操作：questions, answers (问卷及结果)
│       └── StatisticsDao.h/cpp     # 复杂查询：用于生成报表的聚合 SQL (Count, Group By)

2. 关键文件功能详解

src/core/ServerApp.cpp:
功能: 维护一个 QMap<int, ClientSocket*> onlineUsers。
作用: 当医生取消预约时，后台需要通知学生。通过此 Map 可以通过学生 ID 找到其对应的 Socket 连接，进而主动推送消息。

src/logic/BookingHandler.cpp:
功能: 实现复杂的预约状态机。
学生修改预约: 接收请求 -> 调用 ScheduleDao 查医生新时间是否空闲 -> 若空闲调用 AppointmentDao 更新 -> 返回成功。
医生修改预约: 接收请求 -> 调用 AppointmentDao 将状态改为 PENDING_STUDENT_CONFIRM -> 记录新时间 -> 调用 ServerApp 查找学生 Socket -> 推送通知。(需学生同意才可)

src/logic/AdminHandler.cpp:
功能: 响应管理员的“导出表”请求。
实现: 不直接生成 Excel，而是调用 StatisticsDao 获取 JSON 格式的统计数据（如 [{"date": "2023-10", "count": 50}, ...]），发送给客户端，由客户端绘制图表。

src/dao/StatisticsDao.cpp:
功能: 执行复杂的 SQL 统计语句。
示例: 统计“最常遇到的心理问题” -> SELECT tag, COUNT(*) FROM consultationRecords GROUP BY tag ORDER BY COUNT(*) DESC.
